# Command-Line Operating System Kernel (C)

A lightweight command-line operating system kernel written in C.  
This project simulates core OS functionality, including process management and memory handling, to reinforce low-level systems concepts and structured modular design.

---

## Features

- Process creation and management  
- Basic scheduling mechanisms  
- Memory allocation and handling modules  
- Interactive command-line interface  
- Modular architecture with separated system components  

---

## Technologies

- C
- GCC
- Command-line / Terminal environment

---

## Purpose

This project was built to strengthen understanding of operating system fundamentals, low-level programming, and modular system design.
